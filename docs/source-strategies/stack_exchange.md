# Stack Exchange source strategy

- Homepage: https://stackoverflow.com/
- Relevant content: Developer questions and answers about technical problems
- Candidate section/listing: https://stackoverflow.com/questions
- Example detail: Not verified
- Pagination: Not verified
- API or structured data: See evidence; otherwise not verified
- Access status: RequiresPermission
- Access evidence and limits: Question list observed; documented API and version-dependent attribution/licensing require review, including privacy versus attribution. Iran relevance unverified; no collection.
- Authorization: Source-specific terms, robots and permission review required
- Why useful: Medium; distinguish actual user need from a service offer or editorial context.
- Recommended approach: Do not collect; resolve access and verify exact scope. Review terms, exact path permissions, identifier minimization, and storage/deletion before any automated retrieval.
